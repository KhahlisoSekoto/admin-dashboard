# Admin Dashboard — The Odin Project

A modern, highly responsive grid-based administrative dashboard built as part of **The Odin Project's** Full Stack JavaScript curriculum. This application showcases complex layout management using CSS Grid, Flexbox, and semantic HTML structure.

## 🚀 Live Preview
* [View Live Project] https://khahlisosekoto.github.io/admin-dashboard/

## 🛠️ Built With
- **HTML5** — Structured semantic elements (`<main>`, `<nav>`, `<section>`).
- **CSS3** — Powered by dynamic **CSS Grid** for main layouts and **Flexbox** for alignment inside sections.
- **Custom SVG & Vector styling** — Dynamic UI components.

## 💡 Key Features & Learning Highlights
- **Complex Layout Management:** Successfully mastered column-balancing, sidebar navigation placement, and content grid panel distributions.
- **Creative Problem Solving:** Encountered persistent image asset hurdles and pivoted to engineer fully customized, letter-initial avatar badges using pure CSS background styling.
- **Flawless Text Alignment:** Solved multi-line item tracking structures to achieve crisp, perfectly flush presentation down the right-hand panel.

## 📸 Final Layout Design
The interface is broken down into a responsive master layout featuring:
- **Left Sidebar:** Vertical navigation panel containing administrative tools.
- **Top Header:** Clean search bar, user notifications, and action buttons ("New", "Upload", "Share").
- **Main Area:** 6 detailed Project Cards utilizing left-accent color bars.
- **Right Side Panel:** Dedicated, stacked cards for community Announcements and live Trending active users.
